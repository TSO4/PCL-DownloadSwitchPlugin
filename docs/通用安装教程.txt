PCL 下载开关 1.3.2 · 通用安装教程
作者：Real Knife — The Origin of 404

一、先放好文件

把整个 DownloadSwitchPlugin 文件夹，放到 PCL 主程序旁边的“PCL”文件夹里。
每个人的盘符不同，不用照抄别人的路径。

1. 找到你平时打开的 PCL 主程序。
   如果是桌面快捷方式：右键 → 属性 → 快捷方式 → 打开文件所在的位置。
   真正的程序可能叫 pcl.exe、Plain Craft Launcher 2.exe，或你自己改过的名字。
   Windows 隐藏扩展名时，可能看不到最后的 .exe。

2. 找到主程序旁边的“PCL”文件夹并打开。
   这个 PCL 文件夹与主程序在同一层。不是 .minecraft，也不是 mods。
   没有的话，先正常启动一次 PCL；仍没有时，在主程序旁新建名为 PCL 的文件夹。
   保留里面原来已有的文件，不要删除整个 PCL 文件夹。

3. 把收到的 ZIP 完整解压，再复制整个 DownloadSwitchPlugin 文件夹进去。
   不要直接在 ZIP 里运行，也不要只复制一个 exe。

放好后的样子：

你的启动器文件夹
  ├─ PCL 主程序.exe（名称可能不同）
  └─ PCL
      ├─ 原有的其他文件……（保留）
      └─ DownloadSwitchPlugin
          ├─ PCL下载开关.exe
          ├─ PCL备用下载.exe
          ├─ PCL.DownloadSwitch.dll
          ├─ PCL.DownloadSwitch.Native.dll
          ├─ Mono.Cecil.dll
          ├─ source（源码）
          └─ 教程、许可证等文件

进入 DownloadSwitchPlugin 后，要能直接看到这两个 exe 和三个 dll。
不要多套一层 DownloadSwitchPlugin，也不用替换 PCL 主程序。

二、平时怎样恢复下载

1. 先像平常一样打开 PCL，等主界面出现。
2. 打开 DownloadSwitchPlugin 里的“PCL下载开关.exe”。
3. 把右上角面板的“恢复 MC 下载”开关打开。
4. 回到 PCL 的“下载 → 原版游戏”，选择版本，正常下载安装。

手动接入后的开关默认关闭，需要自己打开。
自动接入也默认关闭；只把插件放进去，不会自动运行。
这一模式沿用 PCL 自己的下载源设置和安装流程。

三、备用下载怎样用

PCL 的下载页不能使用时，可以用独立备用模块。
打开面板左下角信息图标 → 左侧“备用下载” → “打开备用下载”。
也可以直接双击“PCL备用下载.exe”，不要求 PCL 的下载代码存在。

1. 检查窗口上方的“安装到游戏目录”。
   从插件进入时，默认是当前 PCL 选中的游戏目录。
   这是包含 versions、libraries、assets 的游戏根目录，常见名字是 .minecraft。
   不要把 DownloadSwitchPlugin 或 mods 当成游戏目录。
   独立打开且没有可读取的当前 PCL 状态时，目录会留空，请手动选择。

2. 要换位置，可直接在“PCL 已添加的游戏目录”下拉框选择。
   列表从当前接入的 PCL 读取；在 PCL 新增目录后，可点击“刷新 PCL 目录”。
   未接入或列表暂不可用时，仍可点击“选择目录”手动选择。
   要新建位置，点击“新建目录”，在弹出的窗口里选好位置并新建文件夹，然后选中它。
   可以给不同整合环境建立不同游戏目录，不必使用固定盘符。

3. 选择下载源、Minecraft 版本和安装类型。
   安装类型包含：原版、Forge、Fabric、NeoForge、Quilt。
   选择加载器后，还要选择相应的加载器版本；列表里没有的组合不会强行安装。
   可在 MC 版本框输入版本号查找；勾选选项可显示快照和历史版本。

   “版本名称”自动带上 MC 与加载器版本，例如 1.21.11-Forge_61.2.4。
   原版默认使用 MC 版本号；你也可直接修改名称，之后切换加载器不会覆盖已手填的名称。
   名称可含中文和空格，不能重名、不能包含路径符号，最多 80 字；不会重命名或覆盖已有版本。

4. 选择 MC 版本后，会自动检测 Java，并显示选中的版本和路径。
   默认开启“自动选择 Java”；切换 MC 版本后重新匹配，检测结果会复用以减少等待。
   找不到时可安装所需 Java 后点“重新检测”，也能点“选择 Java”手动指定 java.exe。
   Forge / NeoForge 安装需要 Java；原版 / Fabric / Quilt 安装本身不需要运行 Java。
   此处选的是安装器使用的 Java；启动游戏时仍由 PCL 选择。
   本模块不会替你修改系统 Java 或全局环境变量。

5. 点击“开始安装”，等待显示“安装完成”。
   安装中可以取消；关闭窗口会询问是否取消并等待清理。
   已有文件不会被覆盖。同名资源索引内容不同时，新版本另用已校验的独立索引；
   Forge / NeoForge 只发布运行所需的库，不把安装中间文件带入游戏目录。
   其他同名文件仍有不同内容时，会停止并显示冲突位置，可新建游戏目录后重试。

6. 回到 PCL 的“版本选择”。
   安装到当前目录时，已验证的 PCL 构建会收到刷新请求；没显示时手动刷新一次。
   安装到其他目录时，在 PCL 的版本选择中添加那个游戏目录，再选择新版本启动。
   插件不会替你改变 PCL 保存的目录设置。
   登录账号、启动游戏和游戏所需 Java 仍由 PCL 负责。

备用模块的下载源：
  自动：列表优先官方，文件优先镜像（BMCLAPI）；请求失败时尝试另一来源。
  官方：使用官方来源。
  镜像（BMCLAPI）优先：有支持的镜像路径时优先镜像，失败后回退官方。
镜像（BMCLAPI）由 bangbang93 提供，是 PCL 也使用的下载镜像服务。
每次打开备用窗口默认“自动”，它不改 PCL 原有的源设置。
本版同时处理最多 16 个文件，校验后复用本地缓存，不主动限制下载速率。
失败来源暂停优先使用 5 分钟，尝试仍可用的来源；实际速度取决于网络和节点。
“官方”模式只使用官方来源；全部来源不可用时仍有有限重试。
Quilt 暂使用官方源。Forge / NeoForge 官方安装器内部发起的请求由安装器自身处理。
文件会按元数据或 Maven 提供的哈希校验，失败会重试或停止。
SHA 校验能检查内容是否一致，不是“绝对安全”或服务器永远可用的证明。

四、版本提示怎么看

“能自动下载，没必要启用这个插件”
  表示检测到 PCL 本身已有下载能力，通常选“否”，直接用 PCL 就行。
  若担心误判，可以回答“是”继续进入辅助面板。
  检测的是程序是否提供下载功能，不代表网络和服务器一定正常。

“结构检查通过，但尚未实测”
  表示新构建的接口看起来匹配，建议先用副本手动试用。
  自动适配不是保证所有未来版本都能用。

“兼容检查不通过”
  会停止接入，避免乱改未知结构。仍可单独打开“PCL备用下载.exe”。
  如果 Mojang / 加载器的安装格式以后改变，备用模块也可能需要更新。

五、自动接入（可选，默认关闭）

先手动验证正常，再点信息图标 → 设置。
勾选“启动 PCL 后自动接入并启用下载”，阅读并确认风险提示。
系统托盘出现后台助手后，下次正常启动同一路径的 PCL，会等待主界面就绪，
检查兼容性，接入插件并启用下载。任务进行中会延后启用。

检测到 PCL 时会出现加载提示：等待就绪 → 检查兼容性 → 接入插件。
主界面连续响应后立即继续，不再固定等待三秒；实际耗时仍取决于 PCL 和电脑。
完成后提示自动收起。点右上角 × 仅隐藏提示，接入会继续；双击托盘图标可重新显示。
失败只暂停这一次 PCL 启动实例，并保留原因与“查看日志”按钮；同一个实例不会循环重试。

已经接入的 PCL 保留你的手动开关状态，不会被助手反复打开开关。
本来就能下载的构建仍会询问是否继续；失败或接入后快速退出只暂停本次。
重新打开同一路径的 PCL，助手会重新显示加载提示、检查兼容性并恢复自动接入。
可反复关闭和启动 PCL 测试界面，不需要反复勾选自动接入。最小化或隐藏原窗口不算重新启动。
其他目录的 PCL 不会触发恢复；原本的自动模式必须已经开启，后台助手也需仍在运行。
短时间退出不等于一定由插件造成，请结合日志判断。

“登录 Windows 时启动后台助手”是另一个选项，也默认关闭。
不勾选它，助手只在本次 Windows 会话内运行。
只有主动开启它，才会创建当前用户的插件启动快捷方式。

托盘右键的“暂停本次接入（下次 PCL 启动恢复）”只跳过当前启动实例，保留自动及登录设置；
“关闭自动接入（保持关闭）”或在设置中取消勾选，会关闭自动模式并移除本插件的登录启动入口。
主动关闭后，重新打开 PCL 也不会自行恢复，需要自己重新开启。
如果旧版已经把自动模式保存为关闭，新版会保留这个设置；请在设置里手动开启一次。
“退出后台助手（本次会话）”只退出助手，保留保存的设置。
移动 PCL 前先关闭自动模式；到新目录手动验证后重新设置。
自动接入不会自动开始备用安装；备用模块仍需自己选版本并点击“开始安装”。

六、按钮与灰色开关

右上角 ×：隐藏面板，保留当前开关状态。
× 左边的横线：原地缩成小胶囊，点击胶囊恢复。
左下角信息图标：简介与作者、源码、SHA-256、日志、设置、备用下载。
PCL 主窗口中按 Ctrl+Alt+D，或再次运行“PCL下载开关.exe”，可以恢复面板。

查看源码：点击信息图标 → “源代码”，在上方选择文件，可选择文字或点“复制全文”。
页面读取编译时嵌入 DLL 的源码文本，以 WPF 只读文本框显示；不联网、不反编译，也不执行这些文本。
压缩包 source 文件夹提供同一份源码及构建脚本，包括自动接入、加载提示、备用下载和 Java 检测。

PCL 或备用模块正在下载、校验、解压、安装时，开关变灰并锁定当前状态。
任务完成、失败或取消后恢复；状态读不到时也会暂时锁定并记日志。
PCL 本身能下载时，恢复开关也无需切换。
只点 × 不等于停用恢复功能；要停用，等任务结束后关闭开关。

七、报错与日志

未找到 PCL：先打开 PCL 并等主界面就绪，或者直接使用“PCL备用下载.exe”。
文件不完整：完整解压，确认两个 exe 和三个 dll 在同一目录。
另一个目录的插件已加载：等任务结束，正常退出 PCL，再启动并运行新版。
权限不足：PCL 和插件使用同一用户、相同权限，通常普通方式启动即可。
路径过长：选择较短的专门游戏目录，不要放进多层套叠的文件夹。
网络失败：检查网络，尝试另一个下载源；不要把校验失败的文件当成成功安装。
安装冲突：保留原文件，选择新目录安装，之后在 PCL 添加该目录。

详情 → 诊断与日志 → 刷新 → 复制日志。
备用窗口也有“查看日志”按钮。
主日志：DownloadSwitchPlugin\data\plugin.log
Forge / NeoForge 详细安装日志：data\installer\jobs\某次任务编号\loader-install.log
接入前就失败时，可以直接打开这些文件。
反馈时提供插件/PCL/MC/加载器版本、错误时间、操作步骤、相关日志。
日志可能含本机路径，转发前先查看；不要把个人 data 整包转发。

八、分享、更新和卸载

分享：转发原始 ZIP 和本教程。源码及许可证已经包含在包里。
更新：关闭自动模式和后台助手，等任务结束并退出 PCL、备用窗口，
然后用新版替换整个插件文件夹；不要混用不同版本的 exe/dll。
保留旧 data 时会保留你原来的设置。新装发布包不含个人 data，自动功能默认关闭。
卸载：先关闭自动/登录启动，退出助手和 PCL，再删除 DownloadSwitchPlugin。
不要删除整个 PCL 文件夹，也不要删除游戏目录。

需要 64 位 Windows 和 .NET Framework 4.8。
已验证范围、源码说明和第三方许可见“使用说明.txt”“验证记录.txt”。
